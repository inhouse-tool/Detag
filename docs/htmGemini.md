<div style="font-size: 1.3rem;">
📁 8.3形式の制限とは？
</div><p><p>
昔のパソコンの OS（MS-DOS など）では、ファイルの名前に厳しいルールがありました。
<a target="_blank" href="https://webtan.impress.co.jp/e/2018/05/08/29126"><sup>Web担当者Forum</sup></a>
<p></p>

<ul>
<li>
ファイル名は 
<strong>
最大8文字
</strong>
</li>
<li>
拡張子は 
<strong>
最大3文字
</strong>
<a target="_blank" href="https://webtan.impress.co.jp/e/2018/05/08/29126"><sup>Web担当者Forum</sup></a>
<p></p>

</li>
</ul>
この仕組みを 
<strong>
「8.3形式（はちてんさんけいしき）」
</strong>
 と呼びます。
<a target="_blank" href="https://webtan.impress.co.jp/e/2018/05/08/29126"><sup>Web担当者Forum</sup></a>
<p></p>
<p>
<div style="font-size: 1.3rem;">
🌐 なぜ「.htm」になったのか？
</div><p><p>
インターネットや Web ページを作るための言葉（HTML）は、もともと UNIX（ユニックス）という別の OS の世界で生まれました。そのため、正式な拡張子は 4 文字の 
<code>.html</code>
 でした。
<p></p>
しかし、当時のマイクロソフトの OS（Windows 3.1 など）でそのファイルを扱おうとすると、
<strong>
「拡張子は3文字まで」というルールのせいで 
<code>.html</code>
 の4文字目が入りきりませんでした
</strong>
。
<a target="_blank" href="https://webtan.impress.co.jp/e/2018/05/08/29126"><sup>Web担当者Forum</sup></a>
<p></p>

そこで、最後の「l」を削って 
<strong>
3文字におさめた 
<code>.htm</code>
 という拡張子が使われるようになった
</strong>
 のです。
<a target="_blank" href="https://webtan.impress.co.jp/e/2018/05/08/29126"><sup>Web担当者Forum</sup></a>
<p></p>
